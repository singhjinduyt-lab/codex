# SuperNova Super App

A premium Material Design 3 super-app prototype for web, Android, iPhone and tablet experiences. It demonstrates authentication entry points, a responsive home dashboard, service modules, wallet, chat, AI assistant, admin analytics, offline-first architecture notes and Firebase-ready schema documentation.

## Features
- Light/dark adaptive theme, gradients, glassmorphism and reduced-motion-friendly animations.
- Responsive layout for mobile, tablet, desktop and web.
- Professional emoji-based icon system with no external runtime dependency.
- Sample modules for food, grocery, medicine, taxi, package delivery, hotels, flights, events, bills, wallet, marketplace, chat, community, AI, health, learning, news/weather, notes/calendar, files, rewards and scanning.
- Documentation for navigation, schema, API boundaries, state management and deployment.

## Run Locally
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```

See `docs/ARCHITECTURE.md` for database schema, API structure and deployment instructions.
