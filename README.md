# YouTube Title & Thumbnail Optimizer (Mobile App)

React Native (Expo) mobile app for creators:

- Paste a video idea and generate optimized title variants.
- Get suggested tags and thumbnail text hooks.
- See an SEO score and CTR prediction.
- Export content to Canva flow via native share + open Canva.
- Includes creator subscription monetization tiers.

## Run locally

```bash
npm install
npm run start
```

Open in Expo Go (iOS/Android), or run:

```bash
npm run android
npm run ios
```
